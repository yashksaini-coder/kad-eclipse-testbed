# Results

Empty on purpose. Nothing has been measured yet.

Every file here is raw JSON emitted by `kad-eclipse-testbed run --output`, named
`<date>-<scenario>.json`, committed alongside the seed it used.

**No number appears in a README, issue, PR, or blog post without a file in this
directory behind it.** That rule is the reason the repository is worth anyone's
attention; the moment it is broken, this becomes another unsubstantiated
proposal on the pile.

Summary tables go in this file once there is anything to summarise.
